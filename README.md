# 🍋 Trading Limón - Versión Global

**Trading Limón** es una plataforma interactiva de simulación financiera y análisis técnico en tiempo real desarrollada en Python con Streamlit. Permite operar y monitorear acciones de grandes empresas y materias primas (*commodities*) globales de manera ágil e intuitiva.

---

## 🚀 Características Principales

* 📈 **Cotizaciones en Vivo:** Obtención de datos del mercado financiero actualizados utilizando la API de Yahoo Finance.
* 💼 **Gestión de Portafolio:** Seguimiento en tiempo real de activos posesionados (Acciones, Metales y Energía) y cálculo del valor total de la cartera.
* ⚡ **Simulador de Operaciones:** Ejecución instantánea de órdenes de **Compra** y **Venta** ajustando el saldo líquido disponible.
* 📜 **Historial de Transacciones:** Registro estructurado de todas las operaciones realizadas durante la sesión.

---

## 🛠️ Tecnologías Utilizadas

* **Lenguaje:** Python 3.x
* **Interfaz Web:** Streamlit
* **Datos Financieros:** `yfinance`
* **Procesamiento de Datos:** Pandas
